# 大肥鱼 HOI4 · 下一阶段计划

> 当前 v1.3.0。核心已通：聊天、同局 AI、A 托管、连续托管、软件自动输入、本地规则规划 0 tokens、国策 effect。
> 但模板/训练/空海军任务仍未验证，自动执行的“控制台状态”还不稳。

## 原则

1. 先机制，后实现；
2. 先稳定，后智能；
3. 能 effect 做的才接；不能的明确说不能；
4. 每条功能必须有真实存档/干净测试环境证据；
5. 本地规则优先，模型只处理复杂判断。

## Phase 0：自动执行稳定性（最高优先）

问题：

- `~` 是切换键；如果控制台已经打开，自动执行会把它关掉，再输入就变成 Unknown command；
- 自动托管连续跑时，可能出现多周 backlog；
- 现在没有“控制台已关闭”的可靠判断。

要做：

- 自动执行前检测/确保控制台关闭；
- 失败时不盲目重试；
- 记录每次执行的 console 状态/截图证据；
- 增加“一次只跑一单”的锁；
- 20 次连续自动执行测试。

验收：

- 20 次自动 `run` 无 Unknown command；
- 每次只执行一单；
- 失败能明确报“控制台状态未知”，而不是静默输错。

**v1.4.0 验收结果：20/20 成功，新增 20 条 SOV 状态，Unknown=0，编译错误=0，最终控制台关闭。**

## Phase 3：本地智能与预算

要做：

- 本地规则库：
  - 海军/工业/陆军/政治四类；
  - 国策关键词匹配；

- 决策日志可回看。

## Phase 4：训练/空海军“一个动作”验证

状态：**软件鼠标被游戏挡住**。v1.4.0 实测：

- `U` 能打开“招募与部署”；
- `SetCursorPos` 能移动鼠标；
- `SendInput` 左键点击面板按钮无反应；
- `PostMessage WM_LBUTTONDOWN/UP` 被当成地图点击，面板关闭/选州；
- 结论：HOI4 使用原始输入，软件注入鼠标不生效。

下一步只试两条：

1. 键盘 Tab/方向键/Enter 能否导航部署/编制界面；
2. HID 鼠标（Pico/Leonardo）单动作。

如果两条都不行，正式 UI 微操暂停，不接进托管。

只验证，不承诺全接管：

- 打开编制设计器，改一个营；
- 训练队列加一个师；
- 设置一个空军任务；
- 设置一个海军任务。

方式：

- 截图/OCR/鼠标点击；
- 每一步失败可回滚；
- 3/3 成功才继续。

验收：

- 一个动作 3 次成功；
- 不破坏存档；
- 失败明确报“UI 层不支持”。
