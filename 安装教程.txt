大肥鱼 HOI4 · 安装教程（v0.9.18）
================================

这是一个《钢铁雄心 4》的 AI 陪玩工具：
你玩一个国家，DeepSeek 扮演另一个国家，和你谈判、结盟、互相算计。

整套东西包括：
1. 外部软件（聊天窗口）
2. 配套 mod（只负责把本局国力写进日志）
3. 一键安装/卸载脚本

不需要 Steam 创意工坊，不需要 NationMind。


一、安装前
----------
需要：
· Windows 10/11
· 《钢铁雄心 4》1.19.*
· 一个 DeepSeek API Key
· 能上网

建议先关掉 HOI4 和 Paradox 启动器。
安装器会改播放集；启动器开着时退出，可能把勾选覆盖掉。


二、解压
--------
把整个 ZIP 解压到一个文件夹，不要在压缩包里直接双击。
路径可以是桌面、D 盘等，不建议放 C:\Program Files。


三、双击“安装.cmd”
------------------
安装器会自动：
1. 找 HOI4 的 mod 目录；
2. 把 mod 复制到：
   Documents\Paradox Interactive\Hearts of Iron IV\mod\dafeiyu_hoi4
3. 把 mod 勾选写进 dlc_load.json；
4. 安装外部软件到：
   %LOCALAPPDATA%\DaFeiYuHOI4
5. 创建桌面快捷方式：
   “大肥鱼 HOI4”和“卸载大肥鱼HOI4”。

如果 Windows 提示“已保护你的电脑”：
点“更多信息” → “仍要运行”。
安装器不会写注册表、不装服务、不改系统目录。

如果没检测到 HOI4：
软件仍会安装，只是启动游戏时需要手动选 hoi4.exe。
也可以先把 HOI4 启动一次，让 Documents 下的目录生成，再重装。


四、第一次打开软件
------------------
首次安装会要求填 DeepSeek API Key。
· Key 只保存在本机；
· 用 Windows DPAPI 加密；
· 不会上传到任何地方。

填完可以点“测试 Key”。测试会消耗少量 tokens。
没有 Key 也能看状态，但不能聊天。


五、确认 mod 已勾选
------------------
打开 Paradox 启动器，进入 HOI4 的“播放集”：
确认 “DaFeiYu HOI4” 是勾选状态。
安装器通常已经帮你勾好；如果没勾，手动勾上。

注意：mod 不能热加载。
游戏已经启动后再勾选，对当前这局无效，必须退出游戏重开。


六、进游戏
----------
1. 双击桌面“大肥鱼 HOI4”；
2. 点“启动游戏”（会带 -debug_mode，控制台才能打开）；
3. 选你想玩的国家，正常开局；
4. 在游戏里过一周，让 mod 写下第一批国力。

然后回到软件：
· 左侧“你：ITA”应该是你玩的国家；
· 如果认错了，点旁边的“改”，手动选；
· 在“AI 国家”里选一个非玩家国家，开始聊天。


七、行动指令怎么粘贴
--------------------
软件不会替你按键盘（HOI4 屏蔽模拟按键），行动是半自动：

1. 在行动窗口生成命令，软件会自动复制；
2. 回游戏，按 ~ 打开控制台；
3. 按 Ctrl+V 粘贴；
4. 按回车执行；
5. 再按一次 ~ 关闭控制台。

~ 在 Esc 下面、数字 1 左边。
控制台打不开，通常是因为游戏没用 -debug_mode 启动；
用软件里的“启动游戏”最稳。

下一周状态更新后，软件会验证行动是否生效。
没生效不一定是软件坏了，可能是游戏条件不满足。


八、AI 国家列表是空的
--------------------
先看软件“帮助 → 复制诊断信息”里的：
mods=0  表示这次游戏启动时没加载 mod
mods=1  表示 mod 已加载

mods=0 的处理：
1. 保存，退出整个 HOI4（不是只退到主菜单）；
2. 启动器确认 DaFeiYu HOI4 勾选；
3. 重新启动游戏，读存档；
4. 过一周，再看软件。

如果 mods=1 但列表还空：
可能还没过一周，或这局存档刚读入；过一周/读一次档再等一周。


九、卸载
--------
双击桌面“卸载大肥鱼HOI4”。
会问是否把聊天记忆备份到 Documents。
卸载会移除软件和 mod，不会动游戏本体和存档。


十、文件在哪
------------
软件：
%LOCALAPPDATA%\DaFeiYuHOI4

mod：
Documents\Paradox Interactive\Hearts of Iron IV\mod\dafeiyu_hoi4

聊天记忆：
%LOCALAPPDATA%\DaFeiYuHOI4\memory.json

更详细说明：
软件目录里的“使用说明.md”，或软件内“帮助”。


十一、常见问题
--------------
Q：安装后启动器里没有 DaFeiYu HOI4？
A：重新运行安装器；或检查 Documents 是否被 OneDrive 重定向。

Q：软件显示“你：GER”，但我玩意大利？
A：点“你：…”旁边的“改”，选意大利；v0.7.1 起也会自动重读。

Q：AI 列表一直空？
A：先看 mods 是不是 0；mod 没加载时，重启游戏才有用。

Q：控制台按 ~ 没反应？
A：用软件“启动游戏”，或给 HOI4 加 -debug_mode 启动项。

Q：杀毒软件报毒？
A：安装器是 PowerShell 脚本，可能被误报；可查看源码后再运行。
   软件不写注册表、不装服务、不联网上传 Key。

Q：能中途换玩家国吗？
A：游戏本身不支持；换国请新开档。
