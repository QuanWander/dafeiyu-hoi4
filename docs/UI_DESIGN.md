# 大肥鱼 HOI4 · UI 设计说明（v1.0）

## 气质

**铁血旧档案**，不是二次元聊天软件。

- 炭黑背景：`#121211`
- 侧栏深铁灰：`#1A1815`
- 卡片：`#24211C`
- 氧化铁红主按钮：`#7A2D26`
- 黄铜/旧金：`#B5925E`
- 钢灰蓝：`#91A8AF`
- 纸白正文：`#E7E0D3`

不使用亮粉、亮蓝、紫色光晕；渐变只做低对比暗部。

## 布局

```
┌──────────── 340px ───────────┬──────────── 806px ────────────┐
│ 品牌 / 玩家 / 控制台状态      │ 国家标题 / 同国参谋 / 复制     │
│ AI 国家选择                   │                              │
│ 国力卡                        │ 聊天记录                     │
│ 操作按钮 3×2                  │                              │
│ 托管一周 / 自动托管           │                              │
│ 本局 / tokens / 版本          │ 输入框 / 发送                 │
│                               │ 状态栏                       │
└───────────────────────────────┴──────────────────────────────┘
```

窗口 1200×720，侧栏 340，聊天区 806。

## 信息层级

1. **我在玩谁**：`你：ENG · 手动`、AI 国家选择；
2. **游戏能不能自动执行**：`● 游戏运行中 · 控制台就绪` 或 `● 运行中 · 缺少 -debug_mode`；
3. **当前国家态势**：工厂、军力、政治、外交；
4. **我能做什么**：启动、设置、行动、记忆、帮助；
5. **她能不能自己过周**：`托管一周`、`自动托管：开`；
6. **本局元信息**：本局、tokens、版本放最底部，不再和按钮重叠。

## 状态色

- 控制台就绪：暗橄榄绿
- 缺少 debug：暗琥珀
- 自动托管开：暗橄榄绿
- 自动托管关：普通卡片
- 高风险：砖红
- 正常：纸白/钢灰

## 交互原则

- 主按钮只有一个视觉重点：托管一周；
- 自动托管是开关，不是第二个主按钮；
- 自动执行期间允许抢前台约 1 秒；
- 所有失败都在聊天区系统气泡说明，不弹无意义错误框；
- 自动托管失败自动回退，不静默。

## 文案

- 不用“AI 角色扮演”“外交官”；
- 用“她在玩这个国家”“自动过周”“下单”；
- 不承诺后台内存直写；
- 不承诺 5 周验收已完成。
